# UI ヒューリスティクス（Layer 3 共通チェックリスト）

UI タスクで使う構造化チェックリスト。LLM に **自由記述でスコアさせず**、各項目に **pass/fail** を返させる。

## 使い方

Layer 3 のスコア計算:
```
score = 10 × (passed_items / total_items)
```

プロジェクト固有の追加項目は `<task_dir>/ui-checks.yaml` に書く（G3: 共通 + プロジェクト固有）。
共通チェック + プロジェクト固有チェックをマージして評価する。

## 共通チェックリスト

### スクロール挙動

- [ ] 横スクロール領域にスクロールバーまたは視覚的ヒント（グラデーション等）があるか
- [ ] モバイル表示で意図しない横スクロールが発生していないか（`overflow-x` 設定）
- [ ] 長いリスト・表に適切な高さ制限と `overflow-y: auto` が設定されているか
- [ ] スクロール位置が操作前後で保持されているか（戻る遷移時等）

### クリック/タップ領域

- [ ] クリック可能な要素がカーソル変化で識別できるか（`cursor: pointer`）
- [ ] リンクとボタンが視覚的に区別されているか
- [ ] タップ領域と視覚的な要素が一致しているか（余白を含めたクリック可能範囲が正しいか）
- [ ] 隣接するタップ領域に十分な間隔があるか（誤タップ防止）

### 画像・メディア

- [ ] 全ての `<img>` に `alt` 属性が設定されているか
- [ ] 画像に `aspect-ratio` または `width/height` 属性があり CLS を防いでいるか
- [ ] 画像が container からはみ出していないか（`object-fit` 適切設定）
- [ ] 遅延読み込み対象画像に `loading="lazy"` があるか（ファーストビュー外）

### タイポグラフィ

- [ ] 見出し階層（h1-h6）のサイズ比が視覚的に妥当か（2-4 段階に収まる）
- [ ] 本文フォントサイズが 14px 以上（モバイル可読性）
- [ ] 行間（line-height）が 1.4-1.7 の範囲か
- [ ] 等幅フォントと可変幅フォントの使い分けが意図的か

### ボーダー・角丸・影

- [ ] border-radius の種類が 3-4 つ以内に収まっているか
- [ ] border の太さが 1-2 種類に収まっているか
- [ ] box-shadow の種類が 3 つ以内に収まっているか
- [ ] デザイントークンを経由しない生値（`#fff`, `16px` 直書き）が少ないか

### カラー

- [ ] テキストと背景のコントラスト比が WCAG AA 以上（4.5:1）か
- [ ] エラー・警告・成功の色が視覚的に区別できるか
- [ ] ダークモード対応がある場合、両モードで読みやすいか
- [ ] 色だけで情報を伝えていないか（色覚多様性への配慮）

### インタラクション・フィードバック

- [ ] ボタンに hover / active / disabled / focus 状態があるか
- [ ] 非同期処理中にローディング表示があるか
- [ ] フォーム送信後に結果（成功・失敗）のフィードバックがあるか
- [ ] エラーメッセージは原因と解決策を示しているか
- [ ] エラーが該当フィールドの近くに表示されているか

### レイアウト・レスポンシブ

- [ ] モバイル（375px）、タブレット（768px）、デスクトップ（1280px）で破綻しないか
- [ ] フォントサイズを 200% にしても layout が壊れないか（WCAG 1.4.4）
- [ ] セーフエリア（iOS の notch 等）が考慮されているか
- [ ] 要素の縦方向のリズム（spacing）に統一感があるか

### ナビゲーション・情報設計

- [ ] 現在位置が分かるか（breadcrumb / active 状態等）
- [ ] プライマリアクションが視覚的に最も目立つか
- [ ] セカンダリアクションがプライマリと誤認されないか
- [ ] 破壊的操作（削除等）に確認ステップがあるか

## プロジェクト固有チェックの追加方法

`<task_dir>/ui-checks.yaml` を作成:

```yaml
ui_checks:
  deterministic:
    - name: "design-tokens-compliance"
      command: "node scripts/check-design-tokens.js"
    - name: "click-target-size"
      command: "npx playwright test tests/click-targets.spec.ts"

  heuristic_checklist:
    - "プライマリアクションに brand primary color が使われているか"
    - "製品固有のアイコンセットが使われているか"
    - "フォームの section header が正しい階層（h2）で書かれているか"
```

deterministic は Layer 2、heuristic_checklist は Layer 3 に加算される。
